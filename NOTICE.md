# Attribution

This is a clean-room board port inspired by the user experience and feature set of
[ThingPulse/esp32-spotify-remote](https://github.com/ThingPulse/esp32-spotify-remote),
which is distributed under the MIT License.

Hardware initialization follows the public examples and pin definitions for the
[Waveshare ESP32-S3-Touch-AMOLED-2.06](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-2.06).

Third-party dependencies retain their own licenses:

- GFX Library for Arduino / Arduino_GFX
- ArduinoJson
- TJpg_Decoder
- ESP32CertBundle
- Espressif Arduino core and ESP-IDF components
